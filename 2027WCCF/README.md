# 第二十五届华盛顿中国文化节 · 2027 网站

多页静态网站，中英双语。视觉风格参照 Culture / Capital 节庆网站模板（米色纸面、衬线标题、红色与墨色色带、细线分隔）。无需构建，直接上传到任意静态托管即可。

## 本地预览

```
python -m http.server 8027
```

然后打开 http://localhost:8027 。

## 页面

首页 index · 简介 about · 往届回顾 review · 舞台演出 stage · 文化体验 experience · 美食街 food ·
大赛 contests · 主办单位 organizers · 参与 join · 图库 gallery

右上角语言开关：**中 / 中/EN（默认，中英双语并排）/ EN**，访客的选择会被记住。

## 如何修改

根目录下的 *.html 是生成出来的，**不要直接改**。请改：

- `_src/pages/<页面>.html`：各页正文（中英文成对书写：`<span lang="zh">` / `<span lang="en">`）
- `_src/footer.html`：页脚
- `_src/build.py` 里的 `PAGES`：菜单名称、页面横幅照片、首页入口卡片文字

改完运行 `python _src/build.py` 重新生成所有页面。

```
css/styles.css        样式
js/main.js            语言切换、移动端菜单、图库筛选与灯箱
js/gallery-data.js    图库照片清单
images/photos/        第二十四届（2026）摄影组“精选100张”压缩版：xxx.jpg 1800px，xxx-sm.jpg 640px
images/logos/         往届合作伙伴 logo（来自 2026 网站）
images/hero-home.jpg  首页主图（开幕式剪彩，摄影组 R1P_6450）
images/map-2026.jpg   第二十四届场地布局图（平面示意图 v3.2）
```
